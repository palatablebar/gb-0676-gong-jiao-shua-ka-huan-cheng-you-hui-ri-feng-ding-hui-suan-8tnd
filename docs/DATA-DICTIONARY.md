# 数据定义

刷卡事件以event_id去重，card保留前导零。route支持1路/01、机场线/A1、火车站线/R1等别名。event_time必须带偏移；业务日为Asia/Shanghai。result仅success可作为行程，失败刷卡隔离。reported为实扣人民币元。票价F1至2026-11-01前为2元，F2为2.50元。

换乘时限按换乘站类型裁决，不做全城统一：普通站60分钟，枢纽站（机场/火车站）90分钟，两程中任一站为枢纽即按枢纽时限；所有时限均为半开区间，恰好截止点排除。这样75分钟的枢纽联程不漏优惠，普通站的75分钟换乘仍被排除，短途不会因全城放宽而不断续优惠。展示站点取时限较长的一程，并记录站点依据与核验状态。同线路无优惠；零付费行程不能延长换乘锚点。站点资料缺失或未核验的换乘标记为“待核”，不给优惠且阻止封存。

先扣1元换乘优惠，再对卡号业务日施加6元封顶。每张卡每个业务日形成唯一应收：receivable_key为`card|business_day`，逐行汇总得day_receivable；批次重复运行不新增额度占用。每条基本票价=实算扣费+换乘优惠+封顶优惠。

业务ID和超大整数按文本保形；Decimal参与数量金额计算，对外序列化为字符串。哨兵集合定义在app/values.py，缺失值不能当零。所有时间带UTC偏移，先转UTC比较，业务日按指定地区划分。区间统一[start,end)。重复业务键保留第一条、完全相同行计重复；值冲突行隔离且保留原值。空文件、全空白、仅表头分开拒绝。

运行清单包括输入sha256、规则版本、参数、生成时刻与耗时。源行编号以CSV解析器的物理结束行号表示，引号内换行不增加记录数。输入超过4MB返回413，非法表头和类型返回422，失效版本复核返回409。
